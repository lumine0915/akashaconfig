# 虚空终端配置

适用于 [虚空终端](https://wiki.metacubex.one) 内核及使用虚空终端内核的客户端的配置文件。

## 关于本配置

本配置涵盖常用业务策略组与地区分组，经历重度强迫症级别的取舍纠结以减少无效冗余配置。采用 `rule-set` 规则集减少内存占用，分流合理精准，且配置了DNS分流以解决DNS污染。

**注意**：本配置不主动处理任何“防泄漏”（如DNS泄漏、WebRTC泄漏等）相关问题。目前无DNS泄漏只是巧合。

## 使用说明

请在`proxy-providers`中添加订阅链接，随后导入客户端即可使用。

### 特殊需求处理

- **局域网/软路由环境**

请**务必更改`authentication`和`secret`中的密码为你自己的密码**。并设置`external-controller`的IP地址为`0.0.0.0`以便于登录控制面板

- **订阅中有私人DNS配置**

请在DNS配置下增加如下条目：

```yaml
proxy-server-nameserver-policy: {订阅的私人DNS配置}
```

订阅的私人DNS配置一般在订阅YAML的`nameserver-policy`中。添加时注意缩进

- **Windows裸核运行**

请注释掉`auto-redirect`
